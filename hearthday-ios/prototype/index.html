Browser companion prototype. This is not the native iOS app. It runs a JavaScript port of the Swift planning core (checked against Swift-generated fixtures) so the experience can be reviewed on any computer. Visuals approximate the SwiftUI design; purchases, notifications and haptics exist only in the native app.

Simulated clock

Time travel lets you walk through a whole bake in a few minutes. Try a plan for tomorrow, start it, jump ahead to mixing, then use Check the dough with a fast rise to see the re-plan options.

Reset

Everything is stored in this browser's localStorage only.
